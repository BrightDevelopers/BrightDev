# Examples

Working examples to help you get started with BrightSign developm

## Available Examples

### [01 - Hello BrightSign](01-hello-brightsign/)

Your first BrightSign deployment. Display an image on a player with just two files and an SD card.

**What you'll learn:**
- The `autorun.brs` entry point
- BrightScript basics
- SD card deployment

### [02 - Debugging Your App](02-debugging-your-app/)

Set up a professional debugging workflow with Chrome DevTools, SSH, and the Diagnostic Web Server.

**What you'll learn:**
- Chrome DevTools via the Chromium Inspector
- SSH and DWS setup for fast deploy cycles
- SCP and VS Code auto-upload for fast iteration
- BrightScript Debugger and system logs
